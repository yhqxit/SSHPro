02第一次连接

在哪点 → 填什么 → 出问题看哪。

打开新建连接

菜单栏「文件 → 新建连接...」（⌘N）　或　站点管理器工具栏「新建连接」

站点管理器标题为「站点管理器」，工具栏还有「管理分组」「密钥管理」「导入导出」。分组默认折叠，可展开查看站点列表；选中站点后右侧显示详情。

连接编辑表单

分区字段与可选项
基本设置连接名称、主机地址、端口、用户名
认证Picker「认证方式」四选一：密码 / 公钥 / 交互式键盘 / ssh-agent（详见下表）
高级字符编码、分组、备注
跳板机 / 代理链见 第 3 章
端口转发见 第 7 章
底部「取消」/「保存」

四种认证方式怎么选

方式需要填什么 / 界面提示
密码SecureField「密码」
公钥「私钥路径」+「浏览...」+「密码短语（可选）」；填好后显示「指纹：…」
交互式键盘界面提示「连接时将提示输入密码」，连接时再输入
ssh-agent界面提示「使用系统 ssh-agent 中已加载的密钥认证（终端先 ssh-add）」
凭据安全：密码只存系统钥匙串，不写入配置文件或导出包。因此导入 / 导出配置后，密码需要重新录入（导入结果提示也会明确写出「密码不会随配置导入，请在站点编辑中重新录入」）。

导入 / 导出配置

在站点管理器列表右键，可用「导入...」与「导出...」菜单，各含两种格式：

  • 「SSHPro 配置包 (.json)」——完整备份自己的站点
  • 「OpenSSH config」——与 ~/.ssh/config 互通

右键菜单里还有一个开关「严格主机密钥校验（拒绝未知主机）」：默认关闭（首次信任模式），打开后未知主机一律拒绝，需先导入 known_hosts。

首次连接的主密钥确认（TOFU）

第一次连某台服务器，会弹出「首次连接到此主机」窗口，列出 主机 / 密钥类型 / SHA256 指纹，并提示「无法确认该服务器的身份。请核对以下指纹是否与服务器管理员提供的一致；确认后才会发送用户名和密码。」

按钮：「拒绝并断开」与「信任并继续」。窗口底部写明「该指纹将写入应用自有 known_hosts；日后若服务器密钥变更，连接会被直接拒绝。」

请真的核对指纹，它是防中间人攻击的关键一步。确认窗口有 30 秒超时，超时会自动断开；这是正常行为，重新连接即可。
出问题看哪：连不上时依次检查 → 主机地址 / 端口是否正确 → 认证方式与服务器端是否匹配 → 用公钥认证时私钥路径与密码短语 → 用 ssh-agent 时是否已 ssh-add → 若提示主机密钥相关错误，转 第 11 章。

03多级跳板（ProxyJump）与 SOCKS5

这是 SSHPro 的核心能力：多级跳板链 + 链首 SOCKS5，全部在一条连接里配置。

在哪点

连接编辑表单 →「跳板机 / 代理链」分区 →「添加跳板机 / 代理」

每加一级，界面按「第 1 级」「第 2 级」… 顺序编号。站点详情里会显示「代理链（N 级）」。

填什么

字段说明
Picker「类型」SSH 跳板 或 SOCKS5 代理
主机 / 端口 / 用户名该级跳板机（或代理）的地址与账号
认证方式SSH 跳板可选密码、私钥路径或「将使用本机 ssh-agent 中的密钥认证」
跳板密码（存钥匙串）SSH 跳板用密码认证时填写
代理密码（可选，存钥匙串）SOCKS5 代理需要认证时填写
界面上的规则原文：「按连接顺序排列；SOCKS5 只能位于链首。密码只存系统钥匙串，不写入配置文件或导出包。」
也就是说：编号越小越靠近本机；SOCKS5 若要使用，必须放在第 1 级，其后才是 SSH 跳板。

与 ssh config 的习惯对照

如果你熟悉命令行的 ProxyJump bastion,inner，界面里就是依次添加「第 1 级 = bastion」「第 2 级 = inner」。每一级的「主机」按上一跳的视角填写（例如内网目标机只写内网地址即可），不要填成从本机可直达的地址。

出问题看哪

  • 报错信息会带上具体级数（如「第 N 级跳板机 … 主机密钥校验未通过」），据此定位是哪一跳，而不是整条链一起猜。
  • 每一级跳板都单独做主机密钥校验；多级链里若某一台重装过系统，也会触发 主机密钥变更 拒绝。
  • 链首用了 SOCKS5 时，注意当前实现为「仅无认证 + CONNECT」，见 第 12 章。
  • 密码类字段不随配置导出，换机导入配置后需重新录入。

04终端

分屏、广播、命令面板、历史、搜索、高亮规则、会话日志。

分屏与独立窗口

终端工具栏「分屏」
  • 最多 3 个窗格；达到上限会提示「窗格已达上限（3 个）」。
  • 窗格上可点「在新窗口打开」把它拖成独立窗口，或「关闭此窗格」关掉。
  • 每个窗格是同站点的独立连接，互不影响。

命令广播（请谨慎使用）

终端工具栏 Toggle「广播」

开启前会二次确认「确认开启命令广播？」，确认按钮为「开启（发送到 N 个会话）」，并明确警示「你的输入将同时发送到所有活跃会话，请确认没有生产环境误操作风险。」开启后顶部显示「广播中 N 个会话」。

生产环境慎用。广播会把你的输入发给所有活跃会话，误操作会被放大 N 倍。

命令面板与历史命令

快捷键作用界面提示
⌘K 快速连接命令面板按名称 / 主机 / 用户名过滤站点并快速连接「输入名称、主机或用户名过滤站点…」；「↑↓ 选择 · 回车连接 · 双击连接 · Esc 关闭」
⌘L 历史命令面板过滤并复用终端里执行过的命令「过滤历史命令…」；空时显示「暂无历史命令（在终端执行命令后自动采集）」；有「清空历史」按钮
⌘F 终端内搜索搜索当前终端内容「搜索终端内容」

会话日志

终端状态栏有录制按钮，悬停提示「开始记录会话日志（自动命名 + 时间戳 + 命令审计，含审计用途）」，录制时状态显示「录制中」。

如实说明：当前版本没有「导出日志」按钮。日志按自动命名规则写到本机，界面内只提供开始 / 停止录制；若需要归档，请自行从本机文件中取用。不要把「导出」当成已有功能去找。

关键字高亮与触发器

菜单栏「SSHPro → 设置…」（⌘,）→「终端规则」Tab →「添加规则」　（设置面板共 3 个 Tab：外观 / 终端规则 / 快捷键）

可填「名称」「关键字 / 正则」，开关「正则」，设「高亮颜色」，并在 Picker「动作」里选 复制 / 日志 / 广播，点「添加」生效；列表里每行可开关或删除规则。

05SFTP 文件管理

既可以复用终端会话，也可以单独登录一条互不影响的文件通道。

入口与导航

菜单栏「连接 → SFTP 文件管理」（⌘⇧F）

顶部工具栏依次提供：后退 / 前进 / 上级目录 /「路径」输入框 / 刷新 /「Home 目录」（图标按钮，鼠标悬停可看到名称）。列表按「名称 / 大小 / 权限 / 修改时间」分列，点击表头可切换升降序。

独立会话

工具栏有「独立会话」入口，连上后显示「断开」，界面说明「可为 SFTP 单独登录服务器（独立会话，不影响终端）」；断开 SFTP 独立连接不影响终端会话。

会话中断时界面显示「SFTP 会话中断」，并提供「尝试恢复 SFTP 连接」或「SFTP 独立连接」按钮。

上传、下载与批量

操作入口
上传「上传文件...」「上传文件夹（递归）...」；空白处右键还有「上传文件到此目录...」
新建「新建文件夹」「新建空文件」
右键菜单打开、下载...、远程编辑、递归下载文件夹...、批量下载 … 个文件...、批量删除选中的 … 项...、上传文件到此目录...、重命名...、更改权限...、删除...
重命名 / 权限「重命名」里填「新名称」；「更改权限」里填「八进制权限（如 755）」并点「应用」，界面自带说明「644=所有者读写，其他人只读；755=所有者全权限，其他人读+执行」

暂停、继续与断点续传（如实说明）

传输时状态栏显示「上传中...」/「下载中...」与「文件 N/M」。传输控制是图标按钮，鼠标悬停可看到名称「暂停传输」/「继续传输」与「取消传输」；暂停时显示「上传暂停」/「下载暂停」，结束时显示「传输完成」或「传输已取消」。

没有独立的「断点续传」按钮。续传是自动机制：中间文件以 .filepart 暂存，中断后重新发起同一传输、或点「继续传输」即可从已传部分接着走。界面上你只需要认识「暂停传输 / 继续传输」这两个控制按钮。

目录同步与比较

工具栏「目录同步/比较」下拉
  • 「与本地目录比较...」——先看差异，再决定同步
  • 「同步本地 → 远程...」
  • 「同步远程 → 本地...」
试用期到期后：SFTP 写操作会被锁定，提示「试用已到期，购买授权后解锁 SFTP 写操作」；此时仍可连接与浏览（只读）。命令广播、断点续传同样需要授权。

06密钥管理

生成、检查、修复、安装公钥、管理 ssh-agent，集中在一个面板。

在哪点

站点管理器工具栏「密钥管理」

面板标题「密钥管理」，左侧为密钥列表，右侧为详情与操作；顶部可「生成密钥…」「导入密钥…」「添加目录」「刷新」。

生成密钥

「生成密钥…」（空列表时也可点「生成新密钥…」）支持三种类型：

类型适用
Ed25519（推荐）新服务器首选
RSA 4096（兼容旧服务器）老系统只认 RSA 时
ECDSA 521特定兼容需求

详情与操作

右侧分区：「文件」（路径、公钥文件、权限）、「密钥信息」（位数、算法、注释）、「指纹」、「公钥内容」；「操作」分区提供：

复制公钥　复制指纹　保存 .pub 文件　安装公钥到服务器…　加载进 ssh-agent　从 agent 移除　修复权限为 0600　在 Finder 中显示

ssh-agent 与权限

「ssh-agent（N 把）」区域可「刷新」「清空 agent」；未加载时提示「agent 未运行，或没有已加载的身份」。若检测到「N 把私钥权限过宽」，点「全部修复」或单把密钥的「修复权限为 0600」。

出问题看哪：私钥权限过宽会被 SSH 拒绝使用 → 用「修复权限为 0600」；带密码短语的密钥加载 agent 失败 → 界面会提示「已加载进 ssh-agent（未加密密钥）。带密码短语的密钥若加载失败，请在连接编辑中确认密码短语后重试」，回到连接表单把「密码短语（可选）」填对即可。

07端口转发（-L / -D / -R）

转发规则写在「连接」里，连上后自动生效。

在哪点

连接编辑表单 →「端口转发」分区 →「添加转发规则」
如实说明：当前版本没有独立的「端口转发」管理窗口，规则就写在连接编辑表单里；站点详情视图也不回显转发规则。要查看或修改已有规则，请回到该连接的编辑表单。

填什么

每条规则有 Picker「类型」与「启用」开关：

类型界面字段适用场景
-L 本地转发监听地址、本地端口、目标主机（SSH 服务器视角）、目标端口把本机一个端口映射到远端服务（如内网数据库）
-D SOCKS5监听地址、本地端口在本机开一个 SOCKS5 代理，让流量经 SSH 服务器出去
-R 远程转发监听地址、本地端口、服务器监听地址（0.0.0.0 = 允许外部回连）、本地目标端口让服务器把端口回连到本机（如临时暴露本机服务）
界面说明原文：「连接成功后自动生效。每条规则使用独立 SSH 会话；-L 把本地端口转发到目标端口，-D 提供本地 SOCKS5 代理（仅无认证 + CONNECT），-R 让服务器把端口回连到本地（需要服务器开启 GatewayPorts）。」

出问题看哪

  • -R 外部无法回连 → 检查服务器是否开启 GatewayPorts，以及「服务器监听地址」是否填了 0.0.0.0。
  • -D 代理不通 → 当前仅支持无认证 + CONNECT，见 第 12 章。
  • 本地端口被占用 → 换一个「本地端口」；规则可用「启用」开关逐条开关。
  • 每条规则使用独立 SSH 会话，规则较多时会建立多条连接，属预期行为。

08外观与效率

设置面板（⌘,）共 3 个 Tab：外观 / 终端规则 / 快捷键。

外观：终端主题

「终端主题」列表旁提示「点击选用 · 自定义主题可编辑/删除」。点选即应用；自定义主题可「编辑此主题」或「删除此主题」，删除前会确认「删除主题「…」？」。

「新建自定义主题」/「编辑自定义主题」表单字段：名称、背景 #RRGGBB、文字 #RRGGBB、字体、字号（12-24），另有「以当前主题为模板」快速带入；按钮「保存并应用」/「保存修改并应用」，并提示「保存后立即生效，无需重启」。

终端规则

见 第 4 章「关键字高亮与触发器」：名称、关键字 / 正则、正则开关、高亮颜色、动作（复制 / 日志 / 广播），点「添加」。

快捷键

默认组合：

动作默认用途
新建连接⌘N打开新建连接表单
打开 SFTP⌘⇧F切换 / 打开 SFTP 文件管理
激活 / 管理 License⌘⇧V打开「授权与激活」

若设置了非法组合，会提示「必须至少包含一个主修饰键（⌘ / ⌃ / ⌥）；仅用 ⇧ 会拦截正常输入」并拒绝保存。

09授权与激活

发现新版本时

弹窗标题「发现新版本 SSHPro X」、分区「本次更新」，按钮四个：

查看更新说明　跳过此版本　稍后　下载更新

  • 「稍后」= 本次关闭，下次仍会提示；「跳过此版本」= 只屏蔽该版本，将来更高版本照常提示。
  • 弹窗写明「下载后把 SSHPro 拖入「应用程序」覆盖旧版本即可。已购买的 License 绑定机器码，升级后继续有效，无需重新激活。」

手动检查的反馈

已是最新：「已是最新版本（SSHPro X）。」；检查失败：「暂时无法检查更新，请稍后重试，或打开购买页查看最新版本。」

11常见问题与排错

打不开 / 提示「已损坏」

执行 xattr -cr /Applications/SSHPro.app，或「系统设置 → 隐私与安全性 → 仍要打开」。放行一次即可。详见 第 1 章。

从 DMG 里直接运行，过一会儿崩溃

把 App 拖进「应用程序」再从那里打开。DMG 卸载后进程访问已卸载卷会导致异常退出。详见 第 1 章。

连不上服务器

  • 核对主机地址、端口、用户名；确认服务器端允许该认证方式。
  • 公钥认证：检查「私钥路径」「密码短语（可选）」，或在 密钥管理 里看指纹是否读得出。
  • ssh-agent：确认已 ssh-add 加载密钥。
  • 配置导入后密码为空：这是设计如此，密码不随配置导入，需在站点编辑里重新录入。
  • 多级跳板：看报错里的级数，逐跳排查，见 第 3 章。

提示「主机密钥已变更」被拒绝连接

错误原文：「⚠️ 主机密钥已变更（…），疑似中间人攻击，已拒绝连接。」这是安全保护，不是故障：首次信任的指纹已写入应用自有 known_hosts，服务器重装 / 换密钥后会硬拒绝。

处理：先通过带外方式向服务器管理员核实确实是换了密钥，再手动删除 ~/Library/Application Support/SSHPro/known_hosts 或 ~/.ssh/known_hosts 中对应条目，重新连接并重新核对指纹。

不要跳过核实直接删条目——这正是中间人攻击最想让你做的事。若开着「严格主机密钥校验（拒绝未知主机）」，未知主机会直接拒绝并提示「严格模式下不接受未登记的主机密钥，请先导入 known_hosts」。

SFTP 传输中断 / 断连

界面显示「SFTP 会话中断」时，点「尝试恢复 SFTP 连接」或「SFTP 独立连接」。已传部分以 .filepart 保留，重新发起或点「继续传输」即可接着传，见 第 5 章。

试用期到期 / 功能变灰

到期后进入只读模式：仍可连接与浏览，但 SFTP 写操作、命令广播、断点续传等被锁定。在「授权与激活」面板购买并导入 License 后解锁，见 第 9 章。

核对安装包是否被篡改

终端执行 shasum -a 256 ~/Downloads/SSHPro-2.4.11.dmg，结果与购买页公示的 SHA256 或 checksums.txt 一致再安装；也可 md5 -q 核对 MD5。不一致请勿安装并邮件联系核实。

怎么反馈问题

菜单栏「帮助 → 发送反馈...」（快捷键 ⌘⇧E 默认未启用，可在设置里开启）。反馈面板有一个可勾选的开关「附带诊断信息（版本 / 系统 / 架构 / 授权状态）」——由你决定是否附带，不勾选就不带。诊断块明确注明「不含主机 / 账号 / 密码 / 密钥」，也绝不会写入连接列表。也可直接发邮件到 82177657@qq.com。

12功能边界（不做什么）

写在最后，也写清楚：省得你买了才发现不合适。

边界说明
平台仅 Apple Silicon (arm64) + macOS 13+；无 Intel Mac / Windows / Linux 版本
公证暂未购买 Apple Developer ID 公证，首次打开需 xattr -cr 手动放行一次
数据与同步配置、凭据、known_hosts 都在本机；无云同步、无团队共享
语言界面目前为简体中文，暂未提供多语言切换
商业条款个人收款，不开发票、不退款；¥199 为当前版本买断，不承诺「终身免费大版本升级」
源码闭源，不提供源码
SOCKS5（-D 转发）仅支持无认证 + CONNECT
-R 远程转发需要服务器开启 GatewayPorts 才能允许外部回连
会话日志界面内可录制，没有「导出日志」按钮
端口转发规则写在连接编辑表单里，没有独立管理窗口，站点详情不回显规则
断点续传自动 .filepart 机制，没有独立「断点续传」按钮
更新方式轻量提示 + 手动下载 DMG 覆盖，不会自动安装
